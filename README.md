> [!WARNING]
>
> ### АНТИВИРУСНЫЕ СРАБАТЫВАНИЯ
>
> В составе zapret используется WinDivert, поэтому антивирус может отреагировать на его файлы.  
> WinDivert перехватывает и фильтрует сетевой трафик и нужен для работы zapret.
> Этот инструмент может применяться как легитимными, так и вредоносными программами, но сам по себе вирусом не является.
>
> **Фрагмент [`readme.md`](https://github.com/bol-van/zapret-win-bundle/blob/master/readme.md#%D0%B0%D0%BD%D1%82%D0%B8%D0%B2%D0%B8%D1%80%D1%83%D1%81%D1%8B) проекта [bol-van/zapret-win-bundle](https://github.com/bol-van/zapret-win-bundle)*
>
> Часть антивирусов классифицирует WinDivert как инструмент повышенного риска или хакерское средство. В результате файл удаляется и отправляется в карантин. В названии обнаружения обычно присутствует `WinDivert` или `Not-a-virus:RiskTool.Multi.WinDivert`.
>
> Добавьте каталог zapret в исключения антивируса либо отключите обнаружение PUA, то есть потенциально нежелательных приложений. Например, Kaspersky предлагает настройку "Обнаруживать легальные приложения, которые злоумышленники часто используют для нанесения вреда". Если вы уверенно понимаете настройки исключений, предпочтительно добавить исключение. В противном случае рекомендуется отключить обнаружение PUA.

## ⚙️Использование

1. Сначала включите Secure DNS, или безопасный DNS.
    * В Chrome активируйте "Использовать безопасный DNS" и выберите поставщика, отличного от "Поставщик по умолчанию".
    * В Firefox включите "DNS через HTTPS", установите режим "Персональный", откройте "Выбрать провайдера/поставщика" и вручную укажите URL. Например: `https://dns.google/dns-query`, поскольку Cloudflare может быть заблокирован.
    * Windows 11 позволяет включить Secure DNS непосредственно в настройках системы. Инструкция приведена [здесь](https://remontka.pro/dns-over-https-windows-11/); для Windows 11 этот вариант рекомендуется.
    * Владельцам роутеров Keenetic нужно активировать параметр "Транзит запросов". При его отключении Secure DNS на компьютере может работать неправильно.

2. Перейдите на [страницу последнего релиза](https://github.com/Rapidsalawning/zapret-discord-youtube/releases/latest) и скачайте архив в формате zip или rar.

3. Откройте свойства загруженного архива и включите флажок "Разблокировать". Для архивов, открытых через 7-Zip или PeaZip, этот шаг не требуется.

4. Извлеките файлы в каталог, в пути к которому нет кириллических символов и специальных знаков.

5. Запустите подходящий сценарий:
    * Для поиска работающей стратегии откройте **`service.bat`** -> `Run Tests` -> `Standard tests` -> `All configs`.
    * Чтобы включить автозапуск, выберите **`service.bat`** -> `Install Service` -> *нужная стратегия*.

## ℹ️Краткие описания файлов

- [**`general.bat ...`**](./general.bat) запускает стратегию вручную.

  Такой запуск удобен для проверки разных вариантов. Результат зависит от множества условий, поэтому **перебирайте стратегии ALT, FAKE и другие, пока не найдёте подходящую именно для вашей системы**.

- [**`service.bat`**](./service.bat) отвечает за автозапуск и дополнительные операции:
  - <ins>**`Install Service`** добавляет выбранную стратегию в автозапуск Windows через services.msc.</ins>
  - **`Remove Services`** удаляет стратегию и WinDivert из служб.
  - **`Check Status`** показывает состояние обхода и служб, включая автозапущенную стратегию и WinDivert.
  - **`Game Filter`** меняет режим обхода для игр и других сервисов, которые используют UDP и TCP на портах выше 1023.  
  **После смены режима стратегию необходимо перезапустить.**  
  Текущее состояние функции отображается в скобках: включена она или выключена.
  - **`IPSet Filter`** включает или отключает обработку сервисов из `ipset-all.txt`.  
  Это может пригодиться при проверке ресурса, который без zapret работает, а с ним перестаёт открываться.  
  В скобках отображается текущий режим:
    - `none` - ни один IP не проходит проверку
    - `loaded` - IP проверяется на наличие в списке
    - `any` - под фильтр попадает любой IP
  - **`Auto-Update Check`** включает или выключает автоматическую проверку обновлений.
  - **`Replace active fakes`** заменяет выбранный активный fake другим файлом из каталога `bin`.
  - **`Update IPSet List`** загружает из репозитория актуальную версию `ipset-all.txt`.
  - **`Update Hosts File`** обновляет hosts <ins>для восстановления веб-версии Telegram и подключения к голосовым чатам Discord.</ins>
  - **`Check for Updates`** вручную проверяет наличие новой версии.
  - **`Run Diagnostics`** ищет распространённые причины неисправности zapret.  
  В завершение можно очистить кэш <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=11 /> `Discord`; это иногда возвращает работоспособность приложения после внезапного сбоя.
  - **`Run Tests`** запускает проверку стратегий:
    - `Standard tests` проверяет сайты, перечисленные в `utils/targets.txt`.
    - `DPI checkers` проверяет DPI у разных провайдеров, включая Cloudflare и Amazon.


## ☑️Распространённые вопросы и проблемы

### После запуска `general*` нет видимого результата

- При запуске стратегии отдельным bat-файлом, а не через service, должен появиться процесс winws.exe, который можно увидеть на панели задач.  
Если он не появился, обратитесь к [#522](https://github.com/Rapidsalawning/zapret-discord-youtube/issues/522).

### Не удаётся подобрать стратегию
- Откройте командную строку с правами администратора.
- Выполните команды по очереди:

    `netsh winsock reset`
  
    `netsh int ip reset all`
  
    `netsh winhttp reset proxy`
  
    `ipconfig /flushdns`

- Перезагрузите компьютер.

### Не открывается Telegram в браузере

Откройте **`service.bat`** и запустите **`Update hosts file`**. Если имеющийся hosts устарел, программа предложит обновить его вручную:  
  - Скопируйте весь текст из открытого Блокнота.
  - Найдите созданную папку, откройте находящийся в ней файл `hosts` текстовым редактором, запущенным от имени администратора.
  - Вставьте скопированные строки в конец `hosts`; если похожие строки уже добавлялись ранее, замените их.
  - Сохраните файл и проверьте соединение ещё раз. При отсутствии результата убедитесь, что hosts действительно был сохранён.

#### Результат не гарантирован. Если веб-версия по-прежнему не работает, используйте [Telegram Desktop](https://github.com/telegramdesktop/tdesktop/releases) с [локальным прокси](https://github.com/Rapidsalawning/tg-ws-proxy) или любым публичным прокси.

### Обход не запускается или перестал работать

> [!IMPORTANT]
> **Стратегии не гарантируют постоянную работоспособность.**
> Обнаружение может привести к тому, что ранее рабочая стратегия через некоторое время перестанет помогать.
> В репозитории собрано много вариантов обхода. Если ни один не подходит, создайте собственную стратегию на основе одной из существующих и измените её параметры.
> Описание параметров доступно [здесь](https://github.com/bol-van/zapret/blob/master/docs/readme.md#nfqws).

- Откройте `service.bat` -> `Run Diagnostics` и проверьте, нет ли ошибок.

- Убедитесь, что адрес нужного ресурса включён в списки доменов или IP-адресов.

- Попробуйте другие варианты, в том числе **`ALT`**, **`FAKE`** и остальные стратегии.

- Выполните полную переустановку по инструкции ниже.

- Дополнительные сведения: [#765](https://github.com/Rapidsalawning/zapret-discord-youtube/issues/765).

### Как полностью обновить или переустановить проект?
- Сначала сохраните ресурсы и данные, которые добавляли самостоятельно.
- Перезапустите устройство.
- Выполните `service.bat` -> `Remove Services`.
- Запустите `service.bat` -> `Run Diagnostics`; исправьте найденные ошибки и в конце подтвердите действие клавишей Y.
- Удалите старый каталог zapret.
- Загрузите актуальную версию [`zapret-discord-youtube-...`](https://github.com/Rapidsalawning/zapret-discord-youtube/releases) со страницы релизов.
- Щёлкните по архиву правой кнопкой мыши и откройте свойства. Если внизу справа есть флажок разблокировки, включите его, нажмите "Применить", затем "ОК".
- Распакуйте архив в новую папку в корне диска, используя путь без пробелов, специальных символов и кириллицы.
- Запускайте разные сценарии `general`, проверяя доступность интернет-ресурсов. Если выбранный вариант не работает, закройте программу через значок замка на панели задач и перейдите к следующей стратегии.
- После выбора рабочего варианта включите автозапуск через `service.bat` -> `Install Service` -> нужная стратегия.

### Игра или приложение не работает при включённом zapret

- Проверьте в `service.bat`, что для `Game Filter` установлено **`disabled`**, а для `IPSet Filter` - **`none`**. Иначе фильтрация может затронуть неожиданные ресурсы.

### Античит сообщает о проблеме с WinDivert

- Используйте инструкцию из https://github.com/bol-van/zapret-win-bundle/tree/master/windivert-hide.

### Windows 7 требует цифровую подпись драйвера WinDivert

- Замените `WinDivert.dll` и `WinDivert64.sys` в каталоге [`bin`](./bin) одноимёнными файлами из [zapret-win-bundle/win7](https://github.com/bol-van/zapret-win-bundle/tree/master/win7).

### После удаления через [**`service.bat`**](./service.bat) WinDivert всё ещё есть среди служб

1. Определите имя службы командой в командной строке Windows. Открыть её можно через Win+R, введя `cmd`:

```cmd
driverquery | find "Divert"
```

2. Остановите службу и удалите её, подставив полученное имя в обе команды:

```cmd
sc stop название_из_первого_шага

sc delete название_из_первого_шага
```

### Не запускается <img src="https://cdn-icons-png.flaticon.com/128/1384/1384060.png" height=18 /> YouTube

- Проверьте, что [Secure DNS настроен](#%EF%B8%8Fиспользование).
- Отключите блокировщик рекламы: известно, что YouTube начал активно бороться с такими расширениями.
- Переберите остальные стратегии, особенно если раньше сервис открывался.
- См. также [#251](https://github.com/Rapidsalawning/zapret-discord-youtube/discussions/251).

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=18 /> Discord

- Убедитесь, что [Secure DNS включён](#%EF%B8%8Fиспользование).
- Сначала желательно выяснить, на какой стратегии открывается сайт YouTube, и запустить её.
- В `service.bat` перейдите в `Run Diagnostics` и выполните очистку кэша Discord.
- Проверьте приложение Discord и определите, помогла ли очистка кэша.
- Откройте Discord в браузере по адресу https://discord.com/app. Если веб-версия работает, можно временно пользоваться ей.
- Если Discord не открывается и в браузере, повторно проверьте все стратегии. Одна и та же стратегия может открыть YouTube, но не Discord.
- Дополнительная информация находится в [#252](https://github.com/Rapidsalawning/zapret-discord-youtube/discussions/252).

### Не работает <img src="https://cdn-icons-png.flaticon.com/128/5968/5968804.png" height=18 /> Telegram

- Попробуйте [tg-ws-proxy](https://github.com/Rapidsalawning/tg-ws-proxy).
- Также можно использовать бесплатные MTProto-прокси, доступные в интернете.

### Не запускаются игры или нет подключения к ним

Игр много, поэтому проверить и исправить работу каждой из них отдельно невозможно.

Универсальная последовательность действий:
- через `service.bat` обновите ipset и включите `Game Filter`;
- если это не помогло, дополнительно активируйте `ipset any`.

Учитывайте, что режим `ipset any` может нарушить открытие многих сайтов. Не оставляйте его включённым постоянно. Вместо этого определите IP-адреса, которые использует игра, и внесите их в `ipset-all.txt`.

Если и после этого игра не работает, создайте тему в разделе [Discussions](https://github.com/Rapidsalawning/zapret-discord-youtube/discussions), а не issue, и дождитесь помощи других игроков.

### В списке нет подходящей проблемы

- Сообщите о ней [здесь](https://github.com/Rapidsalawning/zapret-discord-youtube/issues).

## 🗒️Добавление адресов других ресурсов

Дополнительные адреса для обхода добавляются в следующие файлы:
- **`list-general-user.txt`** предназначен для доменов; поддомены учитываются автоматически.
- **`list-exclude-user.txt`** исключает домены из обработки. Это полезно, например, когда IP сети есть в `ipset-all.txt`, но конкретный домен из неё фильтровать не нужно.
- **`ipset-all.txt`** содержит IP-адреса и подсети.
- **`ipset-exclude-user.txt`** задаёт исключения для IP-адресов и подсетей.
  - Файлы **`*-user.txt`** создаются автоматически при первом запуске `zapret` или `service.bat`.
